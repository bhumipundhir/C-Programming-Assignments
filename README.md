# C Programming Assignments Website

A simple, responsive website that displays my C programming assignments in one place. Pick a program from the menu to see the question and its full source code.

**Made by:** Bhumi Pundhir
**Course:** BCA First Semester, Dezyne École College

## Features

- 20 C programming assignments in a clickable menu
- Question and source code appear on the right when you select a program
- Dark navy theme with a clean, modern layout
- Responsive design that works on desktop and mobile
- Social media icons in the footer using Font Awesome

## Topics Covered

- Else-if ladder and conditional statements
- Loops (while, for)
- Palindrome, prime and Armstrong numbers
- Pattern printing (diamond, triangles)
- Arrays: searching, sorting, finding max values
- Matrices: multiplication, row and column sums
- Strings, series and Fibonacci

## Built With

- HTML5
- CSS3
- JavaScript (only used to load the program files)
- [Font Awesome](https://fontawesome.com/) for icons
